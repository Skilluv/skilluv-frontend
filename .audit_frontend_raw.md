## 4. AUTH & SESSION

### Flow
1. **Register**: `/auth/register` POST â†’ user + csrf_token (non-httpOnly)
2. **Login**: `/auth/login` POST â†’ user + csrf_token + login_method + has_passkey (hydrates auth store)
3. **Refresh**: Auto on 401 via middleware dans `client.ts` (tryRefresh)
4. **Session state**: Stored in cookies (httpOnly `refresh_token`), client-side auth store synced via `/auth/me` on mount
5. **Logout**: `/auth/logout` POST â†’ clears server-side session + client auth store

### Token Management
- **httpOnly Cookie**: `refresh_token` (secure, samesite, server-side refresh)
- **non-httpOnly Cookie**: `csrf_token` (double-submit CSRF on state-changing requests)
- **Header**: `X-CSRF-Token` (echoed from cookie on POST/PUT/PATCH/DELETE)
- **Retry logic**: GET/HEAD auto-retry 3x (1s, 3s, 9s backoff) on network error; POST/PUT/DELETE do NOT retry

### 2FA
- **TOTP**: `/auth/totp/setup` â†’ QR + secret â†’ `/auth/totp/enable` (backup codes)
- **Email 2FA**: `/auth/email-2fa/enable` â†’ optional, needs `/auth/email-2fa/verify` on login
- **Passkeys** (WebAuthn): Registration `/auth/webauthn/register/start|finish`, Login `/auth/webauthn/login/start|finish`
- **Backup codes**: Can replace TOTP code on login

### Enterprise 2FA Gate
- Client-side guard (`enterprise layout`) checks:
  - `auth.user.totp_enabled` OR `auth.hasPasskey` (strong factor) â†’ bypass mandatory setup
  - Else redirect to `/enterprise/onboarding?next=`
- API returns `requires_totp_setup` flag + `login_method` (sso/webauthn bypass check)

### SSO (Enterprise)
- Discovery: `/enterprise/sso/discover?email` (public, checks if SSO available)
- User redirected to OIDC IdP
- Backend returns `AUTH_SSO_REQUIRED` error with `start_url` on API calls if user not provisioned
- Client auto-redirects to OIDC flow URL

### Capabilities (P18.4)
- Loaded via `/users/me/capabilities` (separate from `/auth/me`)
- Cached in `auth.capabilities` store
- Expiry check: `hasCapability()` filters by `expires_at`
- Used to gate features: `community_curator`, `forum_moderator`, `plagiarism_reviewer`, etc.
